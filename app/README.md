## 立ち上げ（この順に）

1. **GAS（SMF BOT v3.3）**
   - miniapp_api.gs を追加
   - コード.gs の doGet の最初の行に次の1行を足す
     `if (e && e.parameter && e.parameter.api && typeof miniApi_ === 'function') return miniApi_(e);`
   - ［デプロイを管理］→ 鉛筆 → 新バージョン → デプロイ（URLは変わらない）
   - ブラウザで「ウェブアプリのURL?api=ouen」を開き、JSONが出ることを確かめる（エディタで miniApiTest でも見られる）
2. **GitHub Pages**
   - smf-assets のリポジトリに app フォルダを作り、index.html と data を置く → https://hiromitsu81.github.io/smf-assets/app/
   - index.html の CONFIG.GAS_URL にウェブアプリのURL（/exec まで）を入れる
   - スマホのブラウザで開いて、3つの画面が出ることを確かめる（?now=2026-11-07T21:30 を付けると当日の表示を試せる）
3. **LINE Developers**
   - SMFの公式アカウントと同じプロバイダーに「LINEミニアプリ」のチャネルを作る（未認証のまま。審査なし）
   - エンドポイントURLに 2 のURLを入れ、発行された LIFF ID を CONFIG.LIFF_ID に入れて置き直す
   - ミニアプリのURL（https://miniapp.line.me/＜LIFF ID＞）をLINEで開いて確かめる。iPhoneとAndroidの両方で
4. **来場者への入口**
   - まずは Instagram・公式サイト・会場のQRポスターにミニアプリのURLを載せる
   - リッチメニューに入れるのは、画像を作り直すので本番前の最後の更新でまとめて（10月中旬までに決める）

## 当日の混雑への備え

- 会場・時間・出演者はGASを通さず、GitHub Pagesのファイルをそのまま読む（何千人が開いても軽い）

- GASが止まっても、タイムテーブルと会場MAPは見られる（おひねりは「いま数字を読み込めません」と出す。サンプルの数字は出さない）
